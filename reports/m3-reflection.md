Milestone 3 Reflection

## Implementation progress
Same as in Milestone 2, the features we decided to drop were also addressed in that milestone.

## Deviation from the original plan
Multiple Selection Update: Users can now filter multiple states and counties, with a maximum of three choices. However, multiple counties can only be selected only when a single state is chosen.

Comparison Update: Users can see the comparison based on the filter in the two line plots and the three business indices.

Expanded Filter Update: As planned in Milestone 2, we expanded the third filter to allow users to color the map based on three business indices in addition to the default microbusiness density. Note that the growth index is now the default selection.

Map Enhancements Update: A legend is added to the map for better interpretability. The map is placed inside a container to improve the layout.

Business Indices Display Update: Instead of displaying business indices at the bottom of the page in the milestone 2, they are now placed within an extra tab.


## Reflection on strength, limitations & potential improvements

Improved UI: Allowing multiple selections for states and counties enables better comparison.

Enhanced Usability: The newly added legend provide a more intuitive experience with the map.

Better Data Organization: Placing business indices in a separate tab provide the better understanding.

## Limitations

Layout Improvements: Better layout is needed. When multiple counties are selected, the layout becomes longer and affect the layout of two charts.  

Improved Color Choices: No color is included in the dashboard background. So, better to add color to enhance user experience.

## Potential Improvements

Enhance the layout design by refining color schemes and improving component alignment.
Introduce interactive tooltips for better data interpretation and usability.
